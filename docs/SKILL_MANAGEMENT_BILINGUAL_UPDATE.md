## How It Works

1. **Language Switching**: Khi user chọn ngôn ngữ từ dropdown (EN/JA/VI), tất cả tiêu đề và label sẽ tự động thay đổi
2. **Menu Updates**: Menu "Skills" sẽ hiển thị tên theo ngôn ngữ được chọn
3. **Form Labels**: Tất cả form label sẽ thay đổi theo ngôn ngữ
4. **Messages**: Toast notifications sẽ hiển thị theo ngôn ngữ
