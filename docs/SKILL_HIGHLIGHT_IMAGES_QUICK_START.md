# Skill Highlight Images - Quick Start Guide

## For Admin Users

### Adding Highlight Images to a Skill

#### Step 1: Go to Skills Management

1. Login to admin panel
2. Navigate to **Admin → Skills**
3. Click **"Add Skill"** or **"Edit"** existing skill

#### Step 2: Create Highlights

1. Scroll to **"Skill Highlights"** section
2. Enter highlight title (e.g., "Component Architecture")
3. Enter description (optional)
4. Click **"Add Highlight"** button
5. Repeat for each highlight you want to create

#### Step 3: Upload Highlight Images

1. Scroll to **"Highlight Images Gallery"** section
2. Click the upload area or drag-and-drop images
3. Select multiple images at once (up to 5MB each)
4. Images will automatically convert to WebP format
5. Wait for upload to complete

#### Step 4: Assign Images to Highlights

1. For each uploaded image, click the **edit (✏️)** button
2. In the modal:
   - Select the highlight from dropdown
   - Add alt text (for accessibility)
   - Add caption (optional)
3. Click **"Save"**
4. Image will now show the highlight badge

#### Step 5: Set Cover Image (Optional)

1. Click the **star (⭐)** icon on an image
2. This image becomes the cover for that highlight
3. Only one cover per highlight is allowed
4. Star icon only appears after highlight is assigned

#### Step 6: Save Skill

1. Click **"Save"** button at bottom of form
2. All highlights and images will be saved
3. You'll see success message

### Managing Existing Highlight Images

#### Edit Image Metadata

1. Click **edit (✏️)** on image
2. Update alt text or caption
3. Click **"Save"**

#### Change Image's Highlight

1. Click **edit (✏️)** on image
2. Select different highlight from dropdown
3. Click **"Save"**

#### Delete Image

1. Click **delete (✕)** on image
2. Confirm deletion
3. Image will be removed

#### Set/Unset Cover Image

1. Click **star (⭐)** to set as cover
2. Click **star (⭐)** again to unset (if already cover)
3. Only one cover per highlight

### Tips & Best Practices

✅ **DO:**

- Use descriptive alt text for accessibility
- Organize images logically by highlight
- Set a representative cover image
- Keep images under 5MB
- Use clear, high-quality images

❌ **DON'T:**

- Upload non-image files
- Upload images larger than 5MB
- Leave alt text empty
- Assign all images to same highlight
- Upload blurry or low-quality images

### Common Tasks

#### Upload 5 images for 3 highlights

1. Create 3 highlights first
2. Upload all 5 images
3. Assign: 2 images → Highlight A, 2 images → Highlight B, 1 image → Highlight C
4. Set cover for each highlight
5. Save

#### Replace an image

1. Delete old image
2. Upload new image
3. Assign to same highlight
4. Set as cover if needed
5. Save

#### Reorganize images

1. Edit each image
2. Change highlight assignment
3. Save each change
4. Verify in preview

### Troubleshooting

**Q: Image upload failed**

- Check file size (max 5MB)
- Check file format (must be image)
- Try uploading again
- Check internet connection

**Q: Can't assign image to highlight**

- Make sure highlight is created first
- Refresh page if highlights not showing
- Try again

**Q: Cover image not showing**

- Make sure image is assigned to highlight first
- Only one cover per highlight allowed
- Try setting different image as cover

**Q: Images not saving**

- Click "Save" button at bottom of form
- Wait for success message
- Check for error messages

### FAQ

**Q: How many images can I upload?**
A: Unlimited, but recommended max 20 per skill for performance

**Q: Can I upload images without assigning to highlight?**
A: Yes, but they won't show as cover images

**Q: What happens if I delete a highlight?**
A: All images assigned to that highlight will also be deleted

**Q: Can I reuse images across highlights?**
A: No, each image belongs to one highlight only

**Q: What image formats are supported?**
A: JPG, PNG, GIF, WebP (all converted to WebP)

**Q: Is there a limit on image dimensions?**
A: No, but very large images may take longer to upload

**Q: Can I edit images after upload?**
A: Yes, you can edit alt text, caption, and highlight assignment

**Q: Are images automatically optimized?**
A: Yes, converted to WebP and compressed
