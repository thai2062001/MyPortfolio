# 🌟 Radiant Growth Portfolio & CMS

A high-performance, premium portfolio platform built with Next.js, TypeScript, and Supabase. Featuring a sophisticated Admin Dashboard with Trilingual Support (English, Japanese, Vietnamese).

## 🚀 Quick Start for New Users

### 1. Database Setup (Supabase)
The easiest way to get started is to use our consolidated schema:
- Follow the [Supabase Quick Setup Guide](./docs/SUPABASE_SETUP.md).
- Use [SUPABASE_SCHEMA_CONSOLIDATED.sql](./SUPABASE_SCHEMA_CONSOLIDATED.sql) in the SQL Editor.

### 2. Environment Configuration
Copy `.env.example` to `.env.local` and fill in your Supabase and Cloudinary credentials.

### 3. Installation
```bash
npm install
npm run dev
```
Port: `8080` (Local)

## 🛠 Features
- **Trilingual Core**: Full support for EN, JA, and VI across all sections.
- **Magic Sync AI**: Automatic translation of your content using AI.
- **Section Management**: Drag-and-drop ordering for all portfolio sections.
- **Premium Aesthetics**: Smooth animations (Framer Motion, GSAP) and responsive layouts.
- **Image Intelligence**: Auto-WebP conversion via Cloudinary integration.
