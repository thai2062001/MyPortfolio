## Auto-Translate Flow

```
Step 1: Fill English Content
┌─────────────────────────────────┐
│ Title: "Amazing Project"         │
│ Description: "This is..."        │
│ Challenge: "The challenge was..."│
│ Solution: "We solved it by..."   │
└─────────────────────────────────┘
         ↓
Step 2: Click Auto Translate Button
┌─────────────────────────────────┐
│ [✨ Auto Translate to 日本語]    │
│ (Shows "Translating..." while    │
│  API processes the request)      │
└─────────────────────────────────┘
         ↓
Step 3: Translation Complete
┌─────────────────────────────────┐
│ Toast: "Auto-translated to      │
│ Japanese"                        │
│                                 │
│ Form switches to Japanese tab    │
│ automatically                    │
└─────────────────────────────────┘
         ↓
Step 4: Review Japanese Content
┌─────────────────────────────────┐
│ Title: "素晴らしいプロジェクト"  │
│ Description: "これは..."         │
│ Challenge: "課題は..."           │
│ Solution: "私たちは..."          │
│                                 │
│ (Can edit if needed)             │
└─────────────────────────────────┘
         ↓
Step 5: Save Project
┌─────────────────────────────────┐
│ Both English and Japanese        │
│ content saved to database        │
└─────────────────────────────────┘
```

## Form States

### Loading State

```
[Save Project] → [Saving...] (disabled)
```

### Auto-Translate Loading

```
[✨ Auto Translate to 日本語] → [Translating...] (disabled)
```

### Error State

```
Alert: "Title, slug, and category are required"
```

### Success State

```
Toast: "Auto-translated to Japanese"
Form switches to Japanese tab
```

## Color Scheme

- **Active Tab**: Sage color (#8B9B7F or similar)
- **Inactive Tab**: Gray (#666666)
- **Button**: Sage background, white text
- **Button Hover**: Sage with reduced opacity
- **Border**: Light gray (#CCCCCC)
- **Text**: Dark gray (#333333)
- **Label**: Medium gray (#666666)
- **Error**: Red (#DC2626)
- **Success**: Green (#10B981)

## Accessibility

- All form fields have labels
- Required fields marked with \*
- Tab order follows logical flow
- Keyboard navigation supported
- Error messages clear and descriptive
- Loading states indicated
- Color not sole indicator of state

## User Interactions

### Tab Switching

- Click tab to switch
- No data loss
- Smooth transition
- Active state clear

### Auto-Translate

- Click button to translate
- Shows loading state
- Displays success message
- Automatically switches tab
- Can edit translated content

### Form Submission

- Click "Save Project"
- Shows loading state
- Validates required fields
- Saves both languages
- Closes form on success

### Image Upload

- Click to upload or drag/drop
- Shows upload progress
- Displays preview
- Can add multiple images
- Can delete images

## Keyboard Shortcuts

- `Tab` - Navigate between fields
- `Shift+Tab` - Navigate backwards
- `Enter` - Submit form (when focused on submit button)
- `Escape` - Close form (if implemented)
